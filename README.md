# Sangseob Jeong

GitHub Pages에서 배포할 수 있는 반응형 정적 웹사이트입니다.

## 파일
- `index.html`: 웹사이트 본문
- `styles.css`: PC/모바일 디자인
- `script.js`: 연도 자동 표시
- `assets/profile.jpg`: 제공한 자기소개 슬라이드에서 잘라낸 프로필 사진

## 공개하는 방법
1. GitHub 계정에 로그인합니다.
2. **Public** 저장소를 만들고 이름을 정확히 `seobprise.github.io`로 설정합니다.
3. 이 폴더 안의 파일 전체(`index.html`, `styles.css`, `script.js`, `assets/`)를 저장소 최상위에 업로드한 뒤 Commit합니다. ZIP 파일 자체를 업로드하지 마세요.
4. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택하고 **main / (root)**로 저장합니다.
5. 잠시 후 `https://seobprise.github.io`에 접속하고, 다른 휴대폰에서도 확인합니다.

## 교수님 MEMBERS.md Pull Request
1. `https://github.com/yijisoo/kaist.biz.69911.projects/blob/main/2026-fall/MEMBERS.md`에 방문합니다.
2. **Fork**로 개인 계정에 복사한 다음 자신의 복사본에서 `2026-fall/MEMBERS.md`를 수정합니다. 저장소 정책에 따라 원본 페이지에서 바로 연필 아이콘을 누르면 Fork 안내가 나타날 수도 있습니다.
3. 기존 표 헤더와 다른 학생의 형식에 맞춰 이름과 웹페이지 URL을 한 줄 추가하고 Commit합니다.
4. **Contribute → Open pull request**를 선택해 원본 저장소의 `main` 브랜치로 PR을 제출합니다.
5. 교수님이 승인·병합하면 명단에 반영됩니다.

## 공개 전 검토
- 현재 소속과 자기소개/사진의 공개에 동의하는지 확인하세요.
- 원본 슬라이드의 LinkedIn QR코드는 넣지 않았습니다. 프로필 주소를 확인한 후 원하면 링크를 추가할 수 있습니다.
- 사내 미공개 프로젝트, 세부 투자금액, 고객 정보, 개인 연락처는 포함하지 않았습니다.
